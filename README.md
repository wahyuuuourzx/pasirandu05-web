# Pasirandu 05 Website

Static website starter reconstructed from the supplied Figma project.

## Run locally
Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Before publishing
- Replace the placeholder Instagram URL in `index.html`.
- Confirm the QRIS image/recipient details.
- Review text against the final Figma copy.
- Add any missing pages/sections from the final design.
